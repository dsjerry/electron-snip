# 示例 · Examples

## basic

最小可运行示例：全局快捷键截图，演示宿主动作（工具条上的「选区尺寸」）、复制与保存回调。

```bash
npm install
npm run example
```

需要本机有显示器；macOS 首次截图会弹出屏幕录制权限引导，授权后需要重启应用。

Minimal runnable example: a global shortcut starts a snip, a host action (“选区尺寸”) appears on the toolbar, and copy / save are handled by the host callback.

```bash
npm install
npm run example
```

A display is required. On macOS the first snip asks for Screen Recording permission; restart the app after granting it.
